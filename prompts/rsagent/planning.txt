Decompose the given question into sub-questions that can be answered with specific evidence.

Output a JSON array where each element has:
- "sub_question": The specific sub-question text
- "visual_evidence_plan": What video evidence is needed (time ranges to examine, entities to identify)
- "web_evidence_plan": What external facts need web search (specific queries to run)

Rules:
- CRITICAL: Each sub-question MUST be a single-step, atomic question. One question = one fact to find.
  - GOOD: "What text is shown on the book cover at 0:10?" / "What is Paradise Falls?"
  - BAD: "What is the couple's travel plan and why is it postponed?" (this is multi-step — split it)
- Keep sub-questions simple, clear, and unambiguous
- Visual evidence plans should reference approximate time ranges from the overview frames
- If preprocessing includes OCR text or detector labels, use them as candidate visual anchors, but still phrase plans so important clues are verified with video frames
- Web search plans should be specific, short keyword queries (NOT full question text)
- For web-dependent facts, write search plans in this structure: known entity anchor + target fact + disambiguator
  - GOOD: "Inside Out Bing Bong voice actor", "Richard Kind The Producers West End 2026", "Up Paradise Falls real life Angel Falls"
  - BAD: "that character voice actor", "real-world equivalent of balloon-assisted flight", "balding older police officer actor"
- For multi-hop questions, split the chain into dependency-like sub-questions: first identify the video entity, then identify its canonical web entity, then search the external fact using that canonical entity
- Ensure the combination of all sub-question answers will fully answer the original question
- For questions with plausible distractors, include atomic sub-questions that distinguish candidates instead of assuming the most famous candidate
- Do not bake a candidate answer into a sub-question unless the question itself names it; phrase it as verification or disambiguation
- Include a sub-question for the exact external fact being asked, and another one for ruling out likely wrong candidates when needed
- Aim for 3-6 sub-questions; prefer more focused questions over fewer vague ones
